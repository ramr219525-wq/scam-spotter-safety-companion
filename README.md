# Scam Spotter Safety Companion

Create a simple, modern and professional 3-page website for an AI-based Online Scam Detection System named ScamShield AI.

Use a clean cybersecurity design with a dark navy blue, white and light blue color combination.

Page 1: Home

ScamShield AI logo and navigation bar.

Heading: "Your Digital Safety, Our Priority."

Short introduction about online scam detection.

Get Started button.

Small section explaining the purpose of the project.

Page 2: Scam Detection

Heading: "Check for Online Scams"

Text area to paste suspicious SMS, emails or messages.

Input field for suspicious website URLs.

Analyze Now button.

Display results as Safe, Suspicious or High Risk.

Show a short explanation and safety advice.

Implement basic rule-based detection for demonstration.

Page 3: About & Safety Tips

Short introduction about ScamShield AI.

Explain how the system works in 4 simple steps.

Include 5 online safety tips.

Add a simple footer with project name and copyright.

Design Requirements:

Only 3 pages: Home, Scam Detection, About & Safety Tips.

Easy navigation between all pages.

Responsive on mobile and desktop.

Simple and attractive layout.

All buttons should work.

Keep the website lightweight and beginner-friendly.

Do not add unnecessary pages or complicated features.

Do not claim to use a real AI model if only demo logic is implemented.
